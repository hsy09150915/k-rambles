내 주식 포트폴리오 히트맵

증권앱 캡처 → OCR → 전체 종목 검색 → 전일 종가 → 히트맵

1. 계좌

2. 캡처 판독

현재 선택한 한 계좌의 캡처를 여러 장 올리세요. 3장 제한 없이 한 장씩 끝까지 처리합니다.

사진을 선택하세요.

3. 판독 결과 확인

OCR은 종목명을 자동 입력하지 않습니다. 수량·평균매수가를 확인한 뒤 종목명을 검색해 선택하세요. 대소문자·띄어쓰기·특수문자는 무시합니다. 종목코드 6자리를 입력하면 가장 확실하게 확인할 수 있습니다. 캡처의 현재가는 종목 식별에 사용하지 않습니다.

4. 히트맵

색상: 전일 종가가 평균매수가보다 높으면 붉은 계열, 낮으면 푸른 계열. 종목을 선택하면 전일 종가를 자동 조회합니다.

계좌번호는 사용하지 않습니다. OCR은 브라우저에서 실행됩니다. 시세 조회에는 인터넷 연결이 필요합니다.
